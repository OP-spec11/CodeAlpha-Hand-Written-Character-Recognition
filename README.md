# Handwritten Character Recognition

This project is a beginner-friendly handwritten digit recognition system built using a CNN model trained on the MNIST dataset.

## Objective
Identify handwritten digits from grayscale images.

## Project Structure
- `models/` - trained model files
- `notebooks_or_scripts/` - training and evaluation scripts
- `results/` - charts and prediction outputs
- `mnist_train.csv` and `mnist_test.csv` - dataset files

## Setup
1. Create a virtual environment
2. Install dependencies from `requirements.txt`
3. Run training script
4. Evaluate model performance

## Workflow
- Data exploration
- Model training
- Validation and evaluation
- Result visualization
